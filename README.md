# Pietro Ferrazzi — personal website

A dependency-free personal research website prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a repository named `ferrazzipietro.github.io` under the `ferrazzipietro` GitHub account.
2. Push these files to the repository's `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. The site will be available at `https://ferrazzipietro.github.io/` after GitHub finishes the first deployment.

For a project repository rather than a user site, publish from the same branch and directory. GitHub will host it at `https://ferrazzipietro.github.io/<repository-name>/`.
